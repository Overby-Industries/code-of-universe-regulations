# Voting Mechanics

*Every voting mechanism in the Aevoric Commonwealth, gathered by body, with
citations back to the instrument that actually governs it.*

- **Status:** Draft
- **Sources:** `PDDC-GOVERNANCE-MECHANICS.md`, `PDDC-TREASURY-AND-FUNDING.md`,
  `progressive-direct-democracy-constitution.md`, `PDDC-AMENDMENT-AND-SAFEGUARDS.md`

## Why this file exists

`PDDC-GOVERNANCE-MECHANICS.md` is the authoritative source for every
mechanic below — this file adds no rule and states no threshold `pddc-*.md`
does not already state. It exists because that document runs to fourteen
Parts covering six institutions, and a reader who only wants to know how a
General Assembly vote actually works has to find TITLE 1 PART 1 inside it.
This file is the index by function instead of by institution: every voting
mechanism in the Commonwealth, in one place, each with the exact citation
to the text that governs it. Where this file and `pddc-*.md` disagree,
`pddc-*.md` governs and this file is wrong.

## General Assembly

| Question | Answer | Source |
|---|---|---|
| Who can vote | Full Avian Members | `PDDC-GOVERNANCE-MECHANICS.md` §2.1(a) |
| How | Electronic or documented ballot, published within 48 hours | §1.6(c) |
| Proxy voting | Not permitted. Asynchronous voting within the participation window counts for quorum | §1.6(d) |

| Deliberation before a vote | Minimum 14 days after a proposal is Cleared for Approach | §2.3(a) |

## Constitutional Court and Capture Tribunal

The Court does not hold votes in the sense the GA, CC, or TA do — it
deliberates and issues reasoned decisions, not ballots. See
[`dispute-resolution.md`](dispute-resolution.md) for how a matter reaches it
and what happens once it does.

## Constitutional amendments

Voting thresholds for changing the PDDC itself — not ordinary legislation —
are calibrated to what is being changed. `PDDC-AMENDMENT-AND-SAFEGUARDS.md`
is authoritative; this row exists only so a reader doesn't have to guess
which document governs a constitutional change versus an ordinary GA vote.

| Type | Threshold | Source |
|---|---|---|
| Type A (Entrenched) | Full Constitutional Convention — never a GA vote alone | `PDDC-AMENDMENT-AND-SAFEGUARDS.md` §2.4–§2.9 |
| Type B | GA supermajority plus membership referendum | `PDDC-TREASURY-AND-FUNDING.md` §3.2(d) is a worked example |
| Type C / Type D | Lower thresholds, calibrated to significance | `PDDC-AMENDMENT-AND-SAFEGUARDS.md` |

## What no vote can do

**No threshold, at any level, can reach a forbidden transition, waive PDDC
§12.6's prohibition on emergency powers, or reduce a right RALC or PDDC
TITLE 4 guarantees.** A unanimous vote of every body in this list is void
on exactly the same terms as a single dissenting vote, if what it enacts is
one of these. `titles/README.md`'s "Constraints on all titles" states the
same limit for the CUR corpus; PDDC §12.6 and §12.3(a) state it for
governance itself. This is not a voting mechanic to route around — it is
the boundary every mechanic above operates inside.
