# Archived Proposals

Empty. Nothing has been resolved yet because nothing has been submitted —
see [`../ACTIVE/`](../ACTIVE). A proposal lands here once it is PASSED,
REJECTED, SUPERSEDED, or WITHDRAWN, with its `Resolution` section in
[`../TEMPLATE.md`](../TEMPLATE.md)'s format filled in. Nothing is deleted
from this folder; a rejected proposal is as much a record as an adopted one.
